# Project instructions

- Use PySide6 for every user interface.
- Keep workbook I/O and data processing outside the UI thread.
- Keep the bottom action bar visible while page content scrolls.
- Store every user-facing string in `config/i18n.py`.
- Never overwrite source files by default.
- Preserve row reconciliation data for every task.
- Add or update tests whenever processing behavior changes.
- Keep UI, models, services, workers, and utilities in separate modules.
