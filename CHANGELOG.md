# Changelog

## 3.0.0

- Combined Excel Splitter Pro 2.7 and Excel Merger Pro 1.2 into one application.
- Replaced the separate Tkinter interfaces with a responsive PySide6 workspace.
- Added live Chinese / English switching across Split and Merge.
- Preserved CSV, blank handling, output modes, naming, conflict, dedupe, aggregation,
  fuzzy join, worksheet consolidation, and best-effort format-copy behaviors.
- Added two- and three-level hierarchy splitting with searchable multi-selection at every
  parent level.
- Added cascading full-data hierarchy value discovery and exact custom scope values.
- Kept same-named child values under different selected parent paths in separate outputs.
- Added cooperative pause, resume, and cancellation checkpoints.
- Added task history, JSON/XLSX/LOG reports, and row reconciliation.
- Added a portable single-file Python launcher.
- Added native Windows installer and macOS DMG release pipelines.
